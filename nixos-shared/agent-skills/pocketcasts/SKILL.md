# Pocket Casts

`./scripts/pocketcasts.py` talks to the unofficial web-player API; `--help` lists every
command. Lists end each line with the episode uuid that `episode`, `notes` and the writes
take; `subs` and `search` print podcast uuids.

- **The episode the user just heard**: `pick`. It takes the latest started history entry,
  skipping one autoplay barely began; `--show`/`--title` narrow it. Say `picked_because`
  in the answer so a wrong pick shows at once.
- `history` holds the last 100 plays; `history --year YYYY` reaches further back.
- An episode that is not in the user's lists: `search --episodes TERM`, or `search TERM`
  and then `episodes P`.
- `notes U` lists transcript URLs. Those marked `pocketcasts` are generated by Pocket
  Casts: no speaker labels, and names come out misspelled.
- "Archived" is `isDeleted` in the JSON; the episode itself still exists.
- Writes sync to the user's phone. Each one prints the state it left and exits 1 if the
  server ignored the request. Not wired up: play now (it switches what the phone plays),
  adding bookmarks (no delete endpoint found), filters, per-show settings.

Exit 1 with `pass … failed` means the gpg key is locked: tell the user to unlock it at the
desktop and stop. Exit 3 from `pick` prints the candidates: rerun with `--uuid` if the
request decides it, else ask with that list.

**Script Execution:** Always invoke scripts by absolute path: resolve `./scripts/` against
this SKILL.md's directory. All scripts use Nix shebangs, so no dependency installation is
needed.
